# Recovery Changelog: June–August 2026

This changelog recovers notable behavior changes that were present in Git history but not consistently represented in canonical module documentation. It is historical; current behavior is defined by the linked module documents.

## June 2026

- Improved parcel creation workflows.
- Added and refined thermal POS sticker printing.
- Added printer settings and routing preferences.
- Continued application-update support.

See [Parcel Operations](PARCEL_OPERATIONS.md), [Parcel Printing](PARCEL_PRINTING.md), and [Client Applications](CLIENT_APPLICATIONS.md).

## July 2026

- Refined the mobile design system and platform-aligned presentation.
- Migrated the mobile application from Expo managed workflow to bare React Native CLI.

See [Client Applications](CLIENT_APPLICATIONS.md) and [Mobile Implementation](MOBILE_APP_IMPLEMENTATION.md).

## August 2026

### Clients, Printing, and Updates

- Modularized parcel-create, receiver-cashier, thermal-sticker, and storage client code.
- Refined the thermal sticker header, wordmark, layout, A5 QR, destination naming, and payment-due copy.
- Routed A5, invoice, and report printing through native desktop printers.
- Migrated Windows desktop packaging to electron-builder and added auto-update support.
- Streamed Windows desktop updates through the application server and private MinIO-backed release process.
- Added private Android APK updates and guarded release clients against local API hosts.
- Added sender-paid parcel creation and reworked A5 acknowledgement behavior.
- Added payer details to A5 documents based on the payment party.
- Added sticker-print audit events and the Sticker Print Usage report.

### Parcel and Payment Operations

- Added SMS settings, MoMo transaction visibility, receiver OTPs, user-employee linkage, company-module access, and printer preferences.
- Added manual MTN MoMo sender-payment flow alongside automated collection.
- Added consignment receiving, scan completeness, OTP verification, and sender-call instructions.
- Preferred booking codes over tracking codes in applicable staff-facing workflows.
- Added original-session amount corrections and pickup OTP phone choice.
- Kept contacted parcels in the call queue and simplified call outcomes.
- Added per-branch pickup and receiver OTP controls with legacy-compatible defaults.
- Added public customer self-service booking drafts and authenticated claim/completion workflows.

See [Parcel Operations](PARCEL_OPERATIONS.md), [Cashier Payments and Shifts](CASHIER_PAYMENTS_AND_SHIFTS.md), and [Self-Service Booking](SELF_SERVICE_BOOKING.md).

### Mobile Operations

- Added mobile cashier, receiver, reporting, and parcel workflows.
- Added rider assignment, current deliveries, history, change requests, and real-time delivery operations.
- Added granular permissions for mobile and rider capabilities.

### Security and Administration

- Enforced permission checks across delivery, inventory, and shipment routes.
- Prevented privilege escalation when permission managers update roles.
- Added System Admin password management with session revocation and audit logging.
- Added test-database isolation and pre-push migration safeguards.

See [Platform and Access Control](PLATFORM_AND_ACCESS.md).

### Help and Intelligence

- Added the in-app Help Center and user manual with sidebar integration.
- Added AI Chat with controlled tool traces.
- Added Executive Insights, Fleet Anomaly Brief, Operations Exceptions Brief, and Management Daily Brief.
- Added shared multi-provider LLM support and rate limiting.
- Added more granular fleet permissions.

See [AI, Help, and Management Insights](AI_HELP_AND_INSIGHTS.md).
